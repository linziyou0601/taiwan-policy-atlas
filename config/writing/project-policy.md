# 專案寫作慣例

本專案使用一般 Markdown 版面，文件與介面採正體中文，原文引用依來源逐字保留。

## 版面

根目錄文件各有一個 H1，H1 下接用途說明。標題依 H1、H2、H3 排列，H2 之間使用空行、`<br>` 與空行，其他細節依 [AGENTS.md](../../AGENTS.md) 與同目錄文件。

## 語言與來源

文件與程式註解使用台灣用語，設定鍵、檔名與程式識別子保留原樣。政見原文、轉錄稿、原文證據與查證來源的內容依來源保留字詞、標點及簡繁，行文調整作用於本專案自己的說明。

## 文案與檢查

介面文案由 `config/app/locale.zh-TW.json` 管理。文件 lint 使用本 repo 的 `rule-writing` 與 `config/writing/layout-profiles.tsv`，程式註解依 `scripts/lint-comments.mjs` 抽取後檢查。

## 翻譯

本專案維護正體中文文件與介面，新增語言版本時依實際語言資源維護對照，檔案路徑、設定鍵與插值參數保持一致。
