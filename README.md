# 台灣政策圖譜

從你關心的議題，了解候選人的政策。先設定議題重視度，再回答由候選人政見寫成的題目。作答時看不到姓名與黨名，結果頁的每個分數都能追溯到選舉公報的原文，翻牌後才顯示身分。網站也收錄主題測驗，以已發表的測驗與長期民調的原題看自己的立場。

<br>

## 功能特色

作答前先選一個題組：一場選舉的選舉比對，或一套主題測驗。選舉比對的流程依序是選擇、選區、議題重視度、作答與結果，主題測驗選好後直接作答。選擇、選區與議題重視度可以回頭修改，作答要一次做完，規則見 [作答](#作答)。

- 選舉取自中選會名冊，先選年度再選職位，選區可以從地圖或清單選取
- 議題重視度沿議題分類樹分配權重，可以細分到第 2 層，也可以略過使用均等權重
- 作答一題一頁，五級量尺或單選題的選項，每題都可以略過
- 候選人做法不同的地方以子題追問，題號與導覽跟著作答路徑調整
- 每個第 1 層議題都有線條圖示，標在作答頁與議題重視度頁
- 作答時與翻牌前遮蔽姓名、搭檔、黨名、暱稱與口號，候選人以甲、乙、丙代稱，翻牌後圖表改用政黨色
- 主題測驗與選舉比對分開計算。8values 政治光譜的題目譯成正體中文，結果是自己在各軸上的位置、各軸的級別與最接近的參照意識形態。兩岸立場照長期民調的原題作答，統獨與身分認同是單選題，統獨題並列陸委會例行民調最新一期的全國比例，條件式獨立與條件式統一各占一條軸，結果列出最接近的類型。台灣地位詮釋是探索性題組，每題附開羅宣言、舊金山和約、2758 號決議等一手文件的節錄，結果是各軸的位置
- 每一題都作答或略過後開放結果頁，選舉比對的結果非零和，立場契合、具體度與議題重疊分開呈現，未表態記為未知並另算涵蓋率
- 總分長條、意識形態雷達、議題 × 候選人熱力圖、分數歸屬桑基圖（可縮放，可展開到每一題）與議題分布 treemap（面積是份量，深淺是契合度）
- 參數即時調整，附 Kendall τ-b 敏感度與全部非常同意、全部中立、全部非常不同意的固定作答檢驗
- 每張卡的說明列出回答的問題、讀法、公式與代入值、資料來源與用到的設定值
- 資料集頁瀏覽題庫、主張、配題、具體度評分、中立性審查、原文與公報影像，以及主題測驗的題目、選項、軸與參照點，匯出 JSON、TSV、CSV
- 分享連結帶資料版本、引擎、設定與詞表雜湊，對方開啟時以唯讀的觀看模式重播同一組答案，對方自己的作答保持原樣。分享圖片先預覽，再下載或複製
- 本機資料依分類匯出與匯入，可匯入自訂題庫 CSV 與設定 JSON，結果標示含自訂資料
- 手機版以底部分頁列切換頁面，結果頁依分區切換卡片，候選人勾選列排成一行左右滑動
- 主題可選跟隨系統、淺色或深色，縮放可選縮小、預設或放大

<br>

| 項目 | 範圍 |

## 建置

網站需要 Node.js 22 以上，資料管線需要 Python 3.10 以上，公報影像的文字辨識需要 macOS。`npm run build` 只建置前端，資料以 `data/` 已提交的管線產物為準。

建置產物寫在 `web/`，包含打包後的程式、樣式、字型、資料集、地圖、設定表與公報影像。網站字型 Chiron GoRound TC 在第一次建置時從 google/fonts 下載，需要網路，下載檔以 sha256 核對後快取在 `.cache/`，之後的建置直接使用快取。

```bash
npm install
npm run build
```

<br>

## 啟動

`npm start` 先建置再啟動本機伺服器，瀏覽器開啟 <http://localhost:8080/>。已建置過時可以只執行 `npm run serve`。

```bash
npm start
```

## 使用方式

### 作答

首頁按「開始作答」進入選擇頁，頁面分成選舉比對與主題測驗。選舉比對選擇年度與職位，地方選舉再到地圖或清單選定選區，總統這類全國性選舉直接進入議題重視度。底部的「上一步」「下一步」可以來回修改。議題重視度設定後按「開始作答」，頁首顯示「已答 x / y 題」與進度條。主題測驗不分選區，也沒有議題重視度，選好一套測驗就進入作答頁。

量尺可以用滑鼠點選，也可以按數字鍵 1 到 5，單選題的選項依序對應數字鍵。作答後停在這一題，可以先改選答案再按「下一題」。「看看候選人怎麼說（姓名已遮蔽）」開啟遮蔽後的原文與判讀理由。主題測驗的作答頁在同一個位置放「原題與出處」，開啟題目的原文、出處與這一題對各軸的影響。

作答要一次做完。作答到一半按「放棄作答」或回到其他頁時會先確認，確定後這次的作答放棄，下次從第一題重新開始，作答中關閉分頁也一樣。重新整理頁面時接著作答。匯入自訂題目後多出的新題，進入作答頁時從第一題未答的題目補上作答，已作答的題目保留答案。

### 結果

每一題都作答或略過後，頁首導覽與步驟列的「結果」才開放。結果頁上方的勾選列點選要比較的候選人，議題分布卡內另有「看哪一位」切換。「翻牌」顯示姓名與黨名，圖表同時換成政黨色，再按一次蓋牌。桑基圖可以放大、縮小與拖曳，切到「每一題」可以從題目一路看到候選人。每張卡右上角的「說明」與右鍵（觸控長按）開啟公式與代入值。

主題測驗的結果頁沒有候選人與翻牌，卡片依題組設定列出：最接近的參照點（距離相同時全部列出）、單選題的選擇與全國對照、各軸偏向兩極的比例、光譜雷達，以及全部參照點依距離由近到遠的排名，計分方式見 [主題測驗的計分](docs/methodology.md#主題測驗)。

### 分享與保存

「分享連結」產生帶作答、議題重視度與參數的網址。對方開啟時進入觀看模式，看到分享者的結果：一律翻牌，只呈現到議題層級，參數不能調整。觀看模式的狀態只留在那個分頁，對方瀏覽器裡自己的作答保持原樣，頁首下方的說明列可以回到自己的作答或開始作答。資料、引擎、設定或詞表的版本與分享時不同時，網站另外提示，連結損壞或版本不相容時以提示說明並開啟首頁。觀看模式的完整規則見 [docs/sharing.md](docs/sharing.md)。

作答只存在瀏覽器的 localStorage，換裝置或清除瀏覽資料前，請到資料集頁的本機資料區匯出檔案。

## 功能限制

政見編碼的範圍見 [資料範圍](#資料範圍)，各項限制與網站的處理方式如下：

| 項目 | 限制與處理 |
|---|---|
| 涵蓋率 | 每位候選人的公報政見只涵蓋部分題目，涵蓋率隨作答變動。2024 總統在預設設定下全部答非常同意、中立或非常不同意時，三組候選人的涵蓋率在 24% 到 44% 之間，結果頁把涵蓋率與上下界一併呈現 |
| 判讀方式 | 主張、配題與評分由模型依判準判讀，審核狀態標為「模型審閱、未經獨立複評」 |
| 主題測驗 | 8values 的題目由英文原題譯成正體中文，作答時按「原題與出處」可以對照原題，各軸權重、參照點的位置與計分方式照原測驗，參照點的位置沒有經過本站審閱。兩岸立場照原句引用題目，條件式統獨題的量尺級數與 TEDS 不同，參照類型由本站命名，見 [各題組的設定](docs/methodology.md#各題組的設定)。全國比例只有統獨題，身分認同題只附政大選研中心長期趨勢的連結。台灣地位詮釋的題目與軸由本站編寫，沒有經過驗證的量表，也未經獨立複評，結果只表示對這些詮釋的同意程度 |
| 現任政府計畫 | 現任者以政府名義宣布的計畫與挑戰者的政見性質不同。已完成的政績不收錄，公報寫成時尚未完成的計畫標為現任政府計畫，例如長照 3.0、囤房稅 2.0，2024 總統共 16 則 |
| 選區界線 | 立委、議員等選區沒有村里層級的界線，選區以所含的鄉鎮對應。跨選區的鄉鎮點選後列出所有相關選區，由清單選定 |
| 自訂資料 | 分享連結不帶自訂資料，自訂題庫與設定只影響匯入的瀏覽器 |

## 隱私權

網站沒有後端，不接任何追蹤或分析服務。作答、議題重視度、參數與自訂資料只寫在瀏覽器的 localStorage，分享連結由使用者自行決定是否傳出。
