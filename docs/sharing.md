# 狀態、分享與自訂資料

網站沒有後端，使用者的狀態只存在瀏覽器的 localStorage，鍵名寫在 `settings.storage.key`。狀態依分類匯出、匯入與重設，分享連結只帶作答與偏好參數。

<br>

## 狀態分類

狀態依下表分類，匯出、匯入與重設都以分類為單位：

| 分類 | 內容 | 分享連結 |
|---|---|---|
| 作答 | 題組（一場選舉或一套主題測驗）、選區、答案與題意雜湊、封存的舊答案 | 帶答案，不帶封存 |
| 偏好與參數 | 議題重視度與是否略過、調整過的參數、翻牌、勾選與議題分布看的候選人 | 帶 |
| 顯示偏好 | 主題、縮放、各頁的檢視狀態，例如資料集的分頁與搜尋、雷達圖隱藏的系列、勾選的匯出分類與匯入方式 | 不帶 |
| 自訂資料 | 匯入的題庫與設定 | 不帶 |

### 題意雜湊

每個答案另外記下作答時的題意雜湊。資料更新後題幹、說明、面向、顯示條件或單選題的選項名稱改變時雜湊不同，舊答案移到封存，作答頁把這一題當成未答。題目已不存在，或作答代碼既不是略過、也不在這一題的量尺或選項中時同樣封存，封存保留最新的 `settings.storage.archiveLimit` 筆。

<br>

## 分享連結

網址格式是 `#/result?s={壓縮後的狀態}`。狀態先寫成 JSON，以 deflate-raw 壓縮後寫成 base64url，題意雜湊保留前 8 碼。壓縮後超過 `settings.share.maxBytes` 時不產生連結，改請使用者匯出檔案。連結損壞或由不相容的版本產生時，網站以提示說明，並開啟首頁。

連結同時記錄下列雜湊。開啟時任何一項與目前不同，網站仍以目前的資料重算，並提示哪一項不同、結果可能與分享者看到的不同：

| 雜湊 | 意思 |
|---|---|
| 資料版本 | 該題組資料集內容的雜湊 |
| 引擎 | `src/` 全部檔案的雜湊 |
| 設定 | `config/app/` 與 `config/tables/` 的雜湊 |
| 詞表 | 受控詞表與待審表的雜湊，主題測驗沒有詞表，記為 `null` |

### 觀看模式

開啟分享連結時，網站以分享的狀態進入觀看模式並前往結果頁。觀看模式的狀態記在 `state.shared`，規則如下：

- 狀態從預設值起算，套用連結帶的作答與偏好，主題與縮放沿用開啟者自己的設定。
- 狀態只放在這個分頁的記憶體，開啟者存在 localStorage 的作答保持原樣。其他分頁改了本機狀態時，觀看中的畫面維持分享的結果。
- 結果一律翻牌，翻牌與重新作答的按鈕收起。
- 結果只呈現到議題層級：layout 標為 `private` 的逐題明細不組，桑基圖只有議題模式，候選人與議題視窗不列逐題的立場與未表態的題目。
- 參數卡列出分享者使用的設定，不能調整。
- 主題測驗沒有候選人與參數卡，結果頁的卡片與自己作答時相同，只收起重新作答的按鈕。
- 只有 `src/cards/actions.js` 的 `SHARED_ACTIONS` 列出的動作會執行：換頁、切換檢視與候選人、開啟說明與明細、分享與顯示偏好。layout 的 `needs` 含 `own` 的頁面（選擇、選區、議題重視度、作答與資料集）以提示卡取代，導覽與步驟列的這些入口鎖住。
- 每一頁的頁首下方有一條說明列。「回到我的作答」丟掉分享的狀態，重新讀取 localStorage 後回到結果頁，「我也來作答」同樣重新讀取後前往選擇頁。

### 分享圖片

結果頁的「分享圖片」先在視窗內預覽，再選擇下載或複製到剪貼簿。圖片畫出作答者與候選人的意識形態雷達，以及排名前 `settings.share.imageRows` 位候選人的總分，資料不足的候選人附上註記，名單較長時頁尾寫出還有幾位。翻牌後雷達與長條是政黨色，含自訂資料時頁尾另外標明。主題測驗的圖片列出每一題單選題選的選項與各軸正極所占的比例，題組用到光譜雷達卡時另畫作答者自己的雷達。說明列寫出最接近的參照點，距離相同時全部寫出，頁尾寫出資料版本與題目來源。圖片的尺寸與版面見 [DESIGN.md](../DESIGN.md)。

## 匯出與匯入

資料集頁的本機資料區可以勾選分類匯出 JSON，各分類也可以分別重設，重設前會確認。匯入時選擇一種方式，套用到檔案內的全部分類：

| 方式 | 行為 |
|---|---|
| 不覆寫 | 只補上目前沒有值的鍵 |
| 附加 | 串列接在後面並去掉重複，物件逐鍵合併，單一值以匯入的為準 |
| 覆寫 | 整類取代 |

<br>

## 自訂題庫

自訂題庫是 CSV，必要欄位與立場欄的前綴寫在 `settings.customData`，資料集頁可以下載目前選區的範本。匯入的立場轉成來源類型為「自訂來源」的主張與配題，權重依 `source-types.tsv`，與公報主張走同一條計分路徑。欄位的寫法：

| 欄 | 寫法 |
|---|---|
| 代碼 | 題目代碼，與資料集重複時略過該題 |
| 面向 | 議題分類樹的代碼 |
| 題幹、說明 | 題目文字 |
| 立場:{號次} | 該號候選人的立場，寫立場判準的名稱，空白或 - 表示未表態 |
| 證據:{號次} | 選填，立場的依據 |

<br>

## 自訂設定

自訂設定是 JSON，只接受 `settings.params` 登錄的參數路徑，型別或範圍不符時不套用並列出問題。
