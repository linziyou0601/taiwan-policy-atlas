# 評分

評分階段為每則主張評具體度，並審查每道題目的中立性。具體度進入網站的總分，中立性全部通過的題目才能發布。

<br>

## 輸入

| 輸入 | 位置 | 說明 |
|---|---|---|
| 配題階段的產物 | `data/40-match/{選舉代碼}/match.json` | 主張、題目與配題 |
| 具體度表 | `data/50-score/{選舉代碼}/specificity.tsv` | 手寫，一則主張對一條判準是一列 |
| 中立性表 | `data/50-score/{選舉代碼}/neutrality.tsv` | 手寫，一道題目對一條判準是一列 |
| 具體度判準與級距、中立性判準 | `config/tables/` 的 `rubric-specificity.tsv`、`rubric-levels.tsv`、`rubric-neutrality.tsv` | 判準的描述寫在表內 |

<br>

## 步驟

具體度的列在 [主張](claims.md) 階段連同主張一起寫入，這個階段審查題目並核對兩張表：

1. 依 [具體度](#具體度) 檢查每則主張對每條判準的評分。
2. 依 [中立性](#中立性) 為每道題目對每條判準各寫一列。有判準不通過時改寫題幹，依 [配題的出題](match.md#出題) 的版本規則處理，重新審查並重新核對這一題的配題。
3. 執行這個階段的核對：

   ```bash
   npm run pipeline -- score run --election <選舉代碼>
   ```

完成判準如下：

| 條件 | 證據 |
|---|---|
| 每道題目的每條中立性判準都通過 | `neutrality.tsv` 的結果欄 |
| 題目說明的現況都已查證 | 查證用的一手來源 |
| 這個階段的核對通過 | `score run` 的結束代碼是 0 |

<br>

## 判讀規則

### 具體度

依 `rubric-specificity.tsv` 各級距欄的描述選 `rubric-levels.tsv` 的級距。只依這則主張的原文評分，同段其他主張的數字與期限屬於其他主張。督促、監督某項建設或政策時，依那項建設或政策本身評分。各級距的證據與理由：

| 級距 | 證據 | 理由 |
|---|---|---|
| 完整明示 | 原文中符合「完整明示」欄的一段 | 「原文寫出『證據』，符合完整明示：判準描述」 |
| 部分明示 | 原文中符合「部分明示」欄的一段 | 「原文寫出『證據』，符合部分明示：判準描述」 |
| 未明示 | - | 原文缺少什麼，寫成「原文沒有說明經費從哪裡來」 |
| 不適用 | - | 為何沒有這個面向，寫成「做法用不到經費」 |

各條判準容易評錯的情況：

| 判準 | 情況 | 評法 |
|---|---|---|
| 條件與取捨 | 原文只寫出群體或地域 | 群體與地域計入對象與範圍，這條判準只看適用條件、排除對象或替代方案 |
| 對象與範圍 | 群體寫在法案或機關的名稱中 | 部分明示 |
| 對象與範圍 | 只寫出合作或交流的對方 | 未明示 |
| 對象與範圍 | 只寫出這場選舉自己的鄉鎮市區 | 未明示 |
| 對象與範圍 | 只寫出要興建或改善的設施類別，沒有指名 | 未明示 |
| 對象與範圍 | 寫出受監督或負責執行的機關 | 機關計入執行方式，這條判準評未明示 |
| 對象與範圍 | 只寫出法定的土地類別 | 部分明示 |
| 財源 | 做法用不到經費 | 不適用 |
| 財源 | 寫出向哪一級政府爭取經費 | 部分明示 |
| 財源 | 只寫結合社會資源 | 未明示 |
| 財源 | 政策是一筆既有款項的分配或運用 | 部分明示 |
| 執行方式 | 寫出由哪個機關執行，或受監督的機關 | 部分明示 |
| 政策工具 | 只寫要達到的目標，或只寫監督、督促而沒有寫出措施 | 未明示 |
| 政策工具 | 既有設施或環境的改善、維護與美化 | 部分明示 |
| 數量與尺度 | 金額或數量只寫概數 | 部分明示 |
| 數量與尺度 | 有確切的數字與基準 | 完整明示 |

### 中立性

中立性表的代碼寫 `{題目代碼}-{判準代碼}`，各判準的審查方式：

| 判準 | 審查方式 |
|---|---|
| 正反可答 | 題幹是可以同意或不同意的政策方向，事實陳述與價值口號改寫成政策方向 |
| 無評價用語 | 比對 `rubric-neutrality.tsv` 這條判準說明欄的評價詞清單 |
| 不洩漏身分 | 比對候選人的姓名、黨名、`aliases.tsv` 與候選人自訂的計畫名稱 |
| 不預設事實 | 有爭議的事實只寫在說明欄，題幹只寫政策方向 |
| 用語可懂 | 專有名詞在說明欄解釋 |
| 單一命題 | 一題只問一個方向。合併兩項時，理由寫明兩項為何是同一個方向 |
| 用字統一 | 題幹的對象與配題主張的對象欄使用詞表的同一個名稱 |

<br>

## 核對

| 核對範圍 | 失敗條件 |
|---|---|
| 具體度 | 主張缺少某條判準的評分，明示的級距沒有原文證據，證據不在主張原文 |
| 中立性 | 題目缺少某條判準的審查，有判準不通過 |
| 方法與審核狀態 | 寫了沒有登錄的名稱 |
