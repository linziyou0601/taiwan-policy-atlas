# 地圖

地圖階段把村里界線合併成縣市、鄉鎮市區與每場選舉的選區，轉成網站直接畫出的 SVG 路徑，並核對每場選舉名冊的涵蓋都找得到圖形。新增選舉的名冊在 [抽取](extract.md) 匯入之後執行。

<br>

## 輸入

| 輸入 | 位置 | 說明 |
|---|---|---|
| 地圖設定 | `data/geo/geography.yaml` | 手寫。來源、基本單位、圖層、座標的小數位數與名稱對照，各鍵的意思寫在檔內的註解 |
| 選區涵蓋表 | `data/geo/scope-areas.tsv` | 手寫。名冊只寫到鄉鎮而選區切開鄉鎮，或名冊的村里在地圖上找不到時，以這張表完整定義選區涵蓋的鄉鎮市區與村里 |
| 圖形來源 | `data/sources.yaml` 登錄的 taiwan-atlas | 內政部村里界線的 TopoJSON 再散布版，已投影成 450 × 600 螢幕座標，金門、連江與烏坵以插圖的方式移到本島左上 |
| 各場選舉的名冊 | `data/20-extract/{選舉代碼}/roster.json` | 選區的縣市代碼、鄉鎮名稱與涵蓋 |

<br>

## 步驟

每次匯入新的名冊之後執行：

1. 轉出地圖並核對名冊，`--offline` 只用已下載的圖形來源。核對沒有通過時，訊息一次列出全部問題：

   ```bash
   npm run pipeline -- geo run
   ```

2. 缺漏的名稱只是用字不同時，在地圖設定的 `name_equivalents` 登錄對照後重新執行。名冊以私用區字元寫的罕用字也在這裡對照。
3. 同一個村里屬於兩個選區時，依選舉區劃分的公告，在選區涵蓋表寫出這幾個選區的全部涵蓋後重新執行。名冊的村里在地圖上找不到時，依村里調整的公告，在選區涵蓋表寫出組成它的舊村里。

完成判準如下：

| 條件 | 證據 |
|---|---|
| 每場選舉每個選區的涵蓋都找得到圖形，同一場選舉沒有村里屬於兩個選區 | `geo run` 的結束代碼是 0 |

<br>

## 判讀規則

選區的涵蓋依序取下列第一個有內容的來源：

| 來源 | 涵蓋 |
|---|---|
| 選區涵蓋表的列 | 每列是一個鄉鎮市區，村里寫 - 時是整個鄉鎮市區，否則是列出的村里 |
| 名冊的 areas | 每格是鄉鎮市區或村里，一格以頓號寫多個村里時拆開。先當鄉鎮市區找，找不到再到選區所在的鄉鎮內找村里 |
| 名冊的 towns | 整個鄉鎮市區 |
| 都沒有 | 整個縣市 |

縣市、鄉鎮市區與選區由村里合併。被一個圖形整圈包住、不屬於任何村里的空白併入那個圖形，邊界與其他村里相鄰的洞照畫。

選區涵蓋表的寫法：

| 欄 | 寫法 |
|---|---|
| 代碼 | `{選區代碼}-{序號}`，序號從 1 起 |
| 選區 | 名冊的選區代碼，含選舉代碼的前綴 |
| 鄉鎮市區 | 地圖上的鄉鎮市區名稱 |
| 村里 | 地圖上的村里名稱，以頓號分隔；整個鄉鎮市區寫 - |

<br>

## 核對

| 核對範圍 | 失敗條件 |
|---|---|
| 圖形 | TopoJSON 的環沒有閉合，設定的圖層或屬性不在來源中，合併的外框接不成閉合的環 |
| 名冊 | 選區的縣市代碼、鄉鎮市區或村里找不到圖形，同一場選舉的村里屬於兩個選區。名冊的「臺」與地圖的「台」等依 `name_equivalents` 視為相同 |
| 選區涵蓋表 | 寫了名冊沒有的選區 |
