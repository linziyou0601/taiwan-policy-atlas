# 地圖

地圖階段把縣市與鄉鎮市區的界線轉成網站直接畫出的 SVG 路徑，並核對每場選舉名冊的縣市與鄉鎮都找得到圖形。新增選舉的名冊在 [抽取](extract.md) 匯入之後執行。

<br>

## 輸入

| 輸入 | 位置 | 說明 |
|---|---|---|
| 地圖設定 | `data/geo/geography.yaml` | 手寫。來源、圖層、座標的小數位數與名稱對照，各鍵的意思寫在檔內的註解 |
| 圖形來源 | `data/sources.yaml` 登錄的 taiwan-atlas | 已投影成 450 × 600 螢幕座標的 TopoJSON，金門、連江與烏坵以插圖的方式移到本島左上 |
| 各場選舉的名冊 | `data/20-extract/{選舉代碼}/roster.json` | 選區的縣市代碼與鄉鎮名稱 |

<br>

## 步驟

每次匯入新的名冊之後執行：

1. 轉出地圖並核對名冊，`--offline` 只用已下載的圖形來源。名冊有鄉鎮找不到圖形時，訊息一次列出全部缺漏：

   ```bash
   npm run pipeline -- geo run
   ```

2. 缺漏的名稱只是用字不同時，在地圖設定的 `name_equivalents` 登錄對照後重新執行。

完成判準如下：

| 條件 | 證據 |
|---|---|
| 每場選舉名冊的縣市與鄉鎮都找得到圖形 | `geo run` 的結束代碼是 0 |

<br>

## 核對

| 核對範圍 | 失敗條件 |
|---|---|
| 圖形 | TopoJSON 的環沒有閉合，設定的圖層或屬性不在來源中 |
| 名冊 | 名冊的縣市代碼或鄉鎮名稱找不到圖形。名冊的「臺」與地圖的「台」依 `name_equivalents` 視為相同 |

<br>
