# 地圖

地圖階段把村里界線投影、簡化成網站的螢幕座標，寫出縣市地圖與各縣市的村里地圖，並登錄村里的異動。地圖不讀任何選舉，選區由 [發布](publish.md#選區涵蓋) 以村里代碼指定。

<br>

## 輸入

| 輸入 | 位置 | 說明 |
|---|---|---|
| 地圖設定 | `data/geo/geography.yaml` | 手寫。來源、投影、村里的屬性、圖層、座標的小數位數與名稱對照，各鍵的意思寫在檔內的註解 |
| 村里異動表 | `data/geo/village-changes.tsv` | 手寫。村里的改名、分割與合併 |
| 圖形來源 | `data/sources.yaml` 登錄的 moi-villages | 內政部國土測繪中心的村里界圖，經緯度的 Shapefile。全部選舉共用最新的一版 |

<br>

## 步驟

1. 轉出地圖，`--offline` 只用已下載的圖形來源：

   ```bash
   npm run pipeline -- geo run
   ```

2. 來源發布新版時，在來源登錄改寫檔名與 sha256，在地圖設定改寫 `shapes` 後重新執行。
3. 地圖重新產生後，各場選舉從發布階段重新執行。

完成判準如下：

| 條件 | 證據 |
|---|---|
| 地圖已轉出，村里異動表的新村里都在地圖上 | `geo run` 的結束代碼是 0 |
| 每場選舉的資料集記的地圖版本與目前的地圖相同 | `npm test` 通過 |

<br>

## 判讀規則

縣市由村里合併，來源的未編定村里也納入縣市。區域方框外的環不畫，面積小於座標精度的環也不畫。

村里異動表的寫法：

| 欄 | 寫法 |
|---|---|
| 代碼 | `{鄉鎮市區代碼}-{序號}`，序號從 01 起 |
| 縣市代碼 | 地圖的縣市代碼 |
| 鄉鎮市區 | 地圖的鄉鎮市區名稱 |
| 舊村里 | 異動前的村里名稱 |
| 新村里 | 地圖上異動後的全部村里，以頓號分隔。分割後沿用舊名的村也寫出 |
| 實施日期 | 公告的實施日期，`YYYY-MM-DD` |
| 依據 | 公告的機關、發文日期與字號 |

<br>

## 核對

| 核對範圍 | 失敗條件 |
|---|---|
| 圖形 | 設定的 Shapefile 不在壓縮檔內，紀錄不是多邊形，合併的外框接不成閉合的環 |
| 村里異動表 | 新村里不在地圖上 |

<br>

## 產物

弧線的座標乘上 10 的 `digits` 次方取整數，第一點寫絕對座標，其後寫與前一點的差。村里的環是帶方向的弧線索引，`~i` 表示第 `i` 條弧線反向使用。地圖版本是全部產物內容的 sha256 前 12 碼。

| 產物 | 位置 |
|---|---|
| 縣市地圖：縣市的代碼、名稱與 SVG 路徑，插圖的方框，來源、名稱對照與地圖版本 | `data/geo/map.json` |
| 村里地圖：這個縣市的座標位數、弧線、村里的代碼、鄉鎮市區、名稱與環，以及村里異動 | `data/geo/villages/{縣市代碼}.json` |
