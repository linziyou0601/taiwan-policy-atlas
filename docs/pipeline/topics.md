# 主題測驗

主題測驗階段核對一套測驗的手寫表與原始檔一致，再發布成題組。主題測驗引用已發表的測驗或長期民調的題目，題目、選項、軸對應與參照點直接寫成手寫表，和選舉的各階段互不相依。計分方式見 [計分方法的主題測驗](../site/methodology.md#主題測驗)。

<br>

## 輸入

| 輸入 | 位置 | 說明 |
|---|---|---|
| 測驗定義 | `data/topics/{代碼}/topic.yaml` | 手寫。名稱與說明、來源與授權、軸、各級門檻與標籤、距離策略、用到的卡片，以及選填的原始檔、核對與全國對照，各鍵的意思寫在檔內的註解 |
| 題目表 | `data/topics/{代碼}/questions.tsv` | 手寫 |
| 選項表 | `data/topics/{代碼}/options.tsv` | 手寫，有單選題時才有 |
| 軸對應表 | `data/topics/{代碼}/question-axes.tsv` | 手寫 |
| 參照點表 | `data/topics/{代碼}/references.tsv` | 手寫 |
| 原始檔 | 測驗定義 `sources` 登錄的網址 | 下載後存在 `.cache/sources/{來源代碼}/` |

<br>

## 步驟

新增一套主題測驗時依序執行，修改既有的測驗時從第 3 步開始：

1. 建立 `data/topics/{代碼}/topic.yaml`：複製另一套測驗的定義改寫。要以原始檔核對手寫表時參考 `8values`，要附全國對照時參考 `cross-strait`。
2. 原始檔登錄在定義的 `sources`。處理這些檔案的 adapter 要有 `topic` 或 `comparison` 能力，沒有時依 [CONTRIBUTING 的修改管線](../../CONTRIBUTING.md#修改管線) 新增。
3. 依 [手寫表](#手寫表) 寫各表。
4. 核對並發布，省略 `--topic` 時發布全部主題測驗，`--offline` 只用已下載的原始檔：

   ```bash
   npm run pipeline -- topics run --topic <代碼>
   ```

完成判準如下：

| 條件 | 證據 |
|---|---|
| 手寫表與原始檔一致，題組已發布 | `topics run` 的結束代碼是 0 |
| 題組索引有這套測驗 | `data/60-publish/index.json` 的 `topics` |

<br>

## 判讀規則

### 手寫表

| 表 | 欄位 |
|---|---|
| `questions.tsv` | 代碼、題幹、簡稱、說明、原文、出處。題幹寫網站顯示的文字，簡稱寫窄處用的短名，說明寫節錄或補充，原文寫原始問卷或測驗的文字，自寫的題目寫 -，出處寫原文或節錄的來源 |
| `options.tsv` | 代碼、題目、名稱。列在這張表的題目是單選題，選項依代碼排列，代碼依問卷的順序編號。每題至少兩個選項，單選題不進任何軸 |
| `question-axes.tsv` | 量尺題對軸的方向、權重與理由，表頭與選舉的軸對應表相同。每一題量尺題至少對應一條軸 |
| `references.tsv` | 代碼、名稱、位置、原文。位置以頓號分隔「軸=位置」，每條軸都要有值 |

### 原始檔核對

定義寫了 `check` 時，這個階段下載或沿用快取並核對 sha256，再由來源登錄的 adapter 讀出原始的題目、權重、參照點與授權全文，與手寫表比對，翻譯不核對。題目、說明或單選題的選項名稱改動時題意雜湊跟著改，使用者的舊答案移到封存。授權全文寫入題組，建置時另存為 `web/licenses/topic-{代碼}.txt`。

### 全國對照

定義的 `comparisons` 每筆對應一題單選題，依來源的授權選用寫法。授權允許轉載時取出比例，授權限制轉載時只附連結：

| 寫法 | 鍵 | 產物 |
|---|---|---|
| 取出比例 | `question`、`source`、`match`、`options`、`none`、`url` | 由來源的 adapter 取出最新一期各選項的比例、無反應的比例、調查名稱、日期、樣本數與執行單位。`options` 把每個選項代碼對到來源的欄名，要涵蓋這題的全部選項。題目的原文要以來源記錄的題目開頭，比例才是同一題的結果 |
| 只附連結 | `question`、`label`、`url` | 只記來源名稱與網址，結果頁附上連結 |

<br>

## 核對

| 核對範圍 | 失敗條件 |
|---|---|
| 定義 | 來源代碼重複或與 `data/sources.yaml` 的來源相同，軸代碼重複，距離的次方不大於 0，標籤數與門檻數不同 |
| 手寫表 | 選項指向沒有登錄的題目，一題只有一個選項，軸對應指向單選題或沒有登錄的軸，方向不是 1 或 -1，權重不大於 0，量尺題沒有軸對應，參照點缺軸或位置超出 0 到 100 |
| 原始檔 | 原文、權重、參照點的位置或筆數與原始檔不同，原始檔的 sha256 與登錄的不同 |
| 全國對照 | 對照的題目不是單選題，選項與 `options.tsv` 不同，來源沒有以 `match` 開頭的題目，原文不是以來源的題目開頭 |

<br>

## 產物

| 產物 | 位置 |
|---|---|
| 題組：題目、選項、軸、參照點、來源與授權、全國對照，格式是 `formats.topic` | `data/60-publish/topics/{代碼}/dataset.json` |
| 題組索引的 `topics`，每筆另帶這套測驗用到的卡片 | `data/60-publish/index.json` |
