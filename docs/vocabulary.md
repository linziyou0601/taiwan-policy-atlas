# 受控詞表與分類樹

每則主張的內容拆分到受控欄位，欄位值要是 `config/tables/vocab-terms.tsv` 已採用的名稱，主張再分配到 `config/tables/taxonomy-issues.tsv` 的面向。同一個概念全站只有一個寫法，不同候選人的主張才能在同一個欄位與面向上比較。兩張表各欄的寫法見 [資料表的設定表欄位](tables.md#設定表的欄位)。

<br>

## 受控欄位

每個欄位回答一個問題，一個概念只屬於一個欄位。數字本身保留在主張的原文欄，欄位只記錄種類。多值以頓號分隔，原文沒有提到的欄位寫 -。各欄的判讀例見 [field-policy](../.claude/skills/policy-curation/references/field-policy.md)。

| 欄位 | 回答的問題 |
|---|---|
| 主體 | 誰執行這項政策 |
| 動作 | 對對象做什麼改變，選擇最貼近原文的一個 |
| 對象 | 政策作用在什麼事物上 |
| 工具 | 以什麼手段達成，可多值 |
| 受益 | 原文點名或對象必然指向的受益群體 |
| 條件 | 適用的門檻或前提 |
| 數量 | 原文數字的種類 |
| 時程 | 原文時間安排的種類 |
| 財源 | 經費從哪裡來 |

<br>

## 分類樹

分類樹依政策作用的事物或制度分類：第 1 層是領域，第 2 層是議題，第 3 層起是候選人方向不同的面向。每個節點的說明列出涵蓋的政策，與兄弟節點的說明沒有重疊。

群體寫在主張的受益欄，以換群體檢驗判斷：把節點名稱裡的群體替換為另一個群體，政策仍屬於同一個父節點、使用同樣的手段時，群體不成為節點。群體自己的地位、權利或制度就是政策的對象時，群體才成為節點。

<br>

## 增修判準

詞與節點的新增、刪除、合併、拆分與改名依本節判斷。每種操作依序檢驗，以第一個成立的檢驗為準。

### 新增

1. 既有的詞或節點的說明涵蓋這個概念時沿用。不同候選人用字不同而概念相同時只登錄一個名稱。
2. 概念屬於另一個欄位時填入那個欄位，群體依換群體檢驗寫在受益欄。
3. 同一個命題只有做法或金額不同時新增子題，題目的寫法見 [question-policy](../.claude/skills/policy-curation/references/question-policy.md#母題與子題)。新節點的題目要能和兄弟節點的題目分別同意或反對。
4. 說明與區分能寫明與每個兄弟節點、同欄位每個詞的分別時新增。
5. 新增的詞與節點至少有一則主張引用。

### 刪除

沒有主張引用的詞與節點刪除，之後的原文引用時再依新增判斷。

### 合併

- 兩個詞或節點的說明無法區分時合併，不同欄位的詞也一樣。
- 沒有通過換群體檢驗的節點，合併到同一父節點下的通用節點，群體填入主張的受益欄。
- 只有一個子節點的父節點，子節點合併到父節點。
- 保留的名稱依序選擇涵蓋較廣、法規或台灣常用、主張用量較多的一個。主張與配題改用保留的詞或節點。

### 拆分

一個節點的配題含兩個能分別同意或反對的命題，而且候選人在兩個命題上的立場不同時，拆分為兩個節點。

### 改名

名稱與說明不符、與其他節點同名或含評價用語時改名。改名只修改名稱，代碼不變，意思改變時依合併或拆分處理。

### 裁定

新詞先登錄到 `vocab-terms.tsv`，狀態寫待審，再依本節的判準裁定。依判準無法判斷時維持待審，交給維護者裁定。分類樹的增修無法判斷或要新增第 1 層議題時，同樣交給維護者裁定。主張引用待審詞時主張層失敗，裁定前不能發布。裁定的經過寫在 commit message。

| 裁定 | 處理 |
|---|---|
| 採用 | 狀態改為採用，加入版本依[版本](#版本)填寫 |
| 駁回 | 刪除這個詞，主張改用裁定時指定的既有詞 |

<br>

## 版本

詞表版本以網站的發行為單位：第一次發行前登錄的詞都是第 1 版，之後兩次發行之間新增的詞寫上一次發行的詞表版本加 1。詞表的版本號是全部詞中最大的加入版本。

各場選舉採用的詞表版本列在網站的更新紀錄頁。
