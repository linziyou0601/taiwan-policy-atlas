# 受控欄位與詞表

每則主張拆進受控欄位，欄位值必須是 `config/tables/vocab-terms.tsv` 已登錄的名稱。同一個概念全站只有一個寫法，不同候選人的主張才能在同一個欄位上比較。

<br>

## 受控欄位

數字本身留在主張的原文欄，欄位只記種類。多值以頓號分隔，原文沒有提到的欄位寫 -。各欄的判讀例見 [field-guide](../.claude/skills/policy-coding/references/field-guide.md)。

| 欄位 | 寫什麼 | 例 |
|---|---|---|
| 主體 | 執行這項政策的機關 | 中央政府、立法院、國軍 |
| 動作 | 主體對對象做的事，選最貼近原文動詞的一個 | 新增、擴大、提高、延長、廢除、制定法律 |
| 對象 | 政策作用的事物，受益的人寫在受益欄 | 社會住宅、基本工資、巴氏量表 |
| 工具 | 達成政策的手段，可多值 | 現金給付、租稅優惠、公共供給、立法 |
| 受益 | 原文點名或對象必然指向的受益群體 | 青年、長者、育兒家庭、勞工 |
| 條件 | 適用的門檻或前提 | 排富、年齡門檻、胎次門檻 |
| 數量 | 原文數字的種類 | 金額、戶數、占國內生產毛額比例 |
| 時程 | 原文的時間安排種類 | 任期內、逐年、指定年份 |
| 財源 | 經費的來源種類 | 政府預算、專款基金、國庫撥補、稅式支出 |

<br>

## 待審詞

詞表沒有適合的名稱時，編碼者把新詞寫進 `vocab-pending.tsv`，裁定寫「待審」，附提出理由與出處。主張引用待審詞時主張層失敗，裁定前不能發布。

| 裁定 | 處理 |
|---|---|
| 採用 | 詞加入 `vocab-terms.tsv`，加入版本寫下一個版本號，待審列的裁定改成採用並寫裁定理由 |
| 駁回 | 改用裁定理由指定的既有詞 |

<br>

## 版本

詞表版本以一次編碼為單位：一次編碼期間新增的詞屬於同一個版本，之後的編碼新增的詞寫下一個版本號。詞表的版本號是全部詞中最大的加入版本。詞表與待審表的雜湊寫進資料集的 manifest 與分享連結，詞表改變時，舊的分享連結會標示詞表不同。

各場選舉採用的詞表版本列在網站的更新紀錄頁，目前的版本與詞數見 [README 的資料範圍](../README.md#資料範圍)。
