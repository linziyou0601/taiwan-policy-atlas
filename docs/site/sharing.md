# 分享與狀態

使用者的狀態怎麼分類與保存、分享連結帶什麼、對方開啟時的觀看模式，以及匯出、匯入與自訂資料的格式。網站沒有後端，狀態只存在瀏覽器的 localStorage，鍵名寫在 `settings.storage.key`。適用於修改 `src/cards/state.js`、`src/cards/share.js` 與 `src/data/custom.js`，或核對分享連結的行為時。

<br>

## 狀態分類

匯出、匯入與重設都以分類為單位，分享連結只帶作答與偏好：

| 分類 | 內容 | 分享連結 |
|---|---|---|
| 作答 | 題組、選區、答案與題意雜湊、封存的舊答案 | 帶答案，封存留在本機 |
| 偏好與參數 | 議題重視度與是否略過、調整過的參數、翻牌、勾選與議題分布看的候選人 | 帶 |
| 顯示偏好 | 主題、縮放與各頁的檢視狀態（`state.view`） | 留在本機 |
| 自訂資料 | 匯入的題庫與設定 | 留在本機 |

### 題意雜湊

每個答案另外記下作答時的題意雜湊。資料更新後雜湊不同的答案移到封存，作答頁把這一題當成未答，封存保留最新的 `settings.storage.archiveLimit` 筆。答案在下列情況封存：

| 題組 | 封存的情況 |
|---|---|
| 選舉 | 題目的題幹、說明、面向、顯示條件或版本改變 |
| 主題測驗 | 題目的題幹、說明或單選題的選項名稱改變 |
| 兩者 | 題目已經移除，或作答的代碼既不是略過、也不在這一題的量尺或選項中 |

<br>

## 分享連結

網址的格式是 `#/result?s={壓縮後的狀態}`。狀態先寫成 JSON，以 deflate-raw 壓縮後寫成 base64url，題意雜湊保留前 8 碼。壓縮後超過 `settings.share.maxBytes` 時改請使用者匯出檔案。連結損壞或由不相容的版本產生時，網站以提示說明並開啟首頁。

連結同時記錄四個雜湊。開啟時任何一項與目前不同，網站仍以目前的資料重新計算，並提示哪一項不同、結果可能與分享者看到的不同：

| 雜湊 | 意思 |
|---|---|
| 資料版本 | 這個題組資料集內容的雜湊 |
| 引擎 | `src/` 全部檔案的雜湊 |
| 設定 | `config/app/` 與 `config/tables/` 的雜湊 |
| 詞表 | 受控詞表的雜湊，主題測驗沒有詞表，記為 `null` |

### 觀看模式

開啟分享連結時，網站以分享的狀態進入觀看模式並前往結果頁，狀態記在 `state.shared`。觀看模式依下列規則：

- 狀態從預設值起算，套用連結帶的作答與偏好，主題與縮放沿用開啟者自己的設定。
- 狀態只放在這個分頁的記憶體，開啟者存在 localStorage 的作答保持原樣。其他分頁改了本機狀態時，觀看中的畫面維持分享的結果。
- 結果一律翻牌，翻牌與重新作答的按鈕收起。
- 結果只呈現到議題層級：layout 標為 `private` 的逐題明細略過，桑基圖只有議題模式，候選人與議題視窗只列到議題。
- 參數卡列出分享者使用的設定，是唯讀的鍵值清單。
- 主題測驗的結果頁與自己作答時相同，只收起重新作答的按鈕。
- 只有 `src/cards/actions.js` 的 `SHARED_ACTIONS` 列出的動作會執行。layout 的 `needs` 含 `own` 的頁面是選擇、選區、議題重視度、作答與資料集，這些頁面以提示卡取代，導覽與步驟列的入口鎖住。
- 每一頁的頁首下方有一條說明列。「回到我的作答」丟掉分享的狀態，重新讀取 localStorage 後回到結果頁，「我也來作答」同樣重新讀取後前往選擇頁。

### 分享圖片

結果頁的「分享圖片」先在視窗內預覽，再選擇下載或複製到剪貼簿。選舉比對的圖片列出排名前 `settings.share.imageRows` 位候選人，名單較長時頁尾寫出還有幾位，含自訂資料時頁尾另外標明。圖片的尺寸與版面見 [元件的規格的分享圖片](components.md#分享圖片)。

## 匯出與匯入

資料集頁的本機資料區可以勾選分類匯出 JSON，各分類也可以分別重設，重設之前先確認。匯入時選擇一種方式，套用到檔案內的全部分類：

| 方式 | 行為 |
|---|---|
| 不覆寫 | 只補上目前沒有值的鍵 |
| 附加 | 串列接在後面並去掉重複，物件逐鍵合併，單一值以匯入的為準 |
| 覆寫 | 整類取代 |

<br>

## 自訂題庫

自訂題庫是 CSV，必要欄位與立場欄的前綴寫在 `settings.customData`，資料集頁可以下載目前選區的範本。匯入的立場轉成來源類型為「自訂來源」的主張與配題，權重依 `source-types.tsv`，與公報主張走同一條計分路徑。分享連結只帶作答與偏好，自訂題庫只影響匯入的瀏覽器。各欄的寫法：

| 欄 | 寫法 |
|---|---|
| 代碼 | 題目代碼，與資料集重複時略過這一題 |
| 面向 | 議題分類樹的代碼 |
| 題幹、說明 | 題目的文字 |
| 立場:{號次} | 這一號候選人的立場，寫立場判準的名稱，空白或 - 表示未表態 |
| 證據:{號次} | 選填，立場的依據 |

<br>

## 自訂設定

自訂設定是 JSON，只接受 `settings.params` 登錄的參數路徑。型別或範圍不符的參數略過，並列出每一筆的問題。
