一、暖心民生，照顧每個家庭
( 一 ) 爭取 849 公車尖峰增班，延伸至烏來部落便利站，解決學生及區民通勤需求。
( 二 ) 爭取「烏來行動加油站」，每週至少 3 次進入部落，讓族人就近加油。
( 三 ) 打造幸福無礙交通：改造社區巴士無障礙設備，推動「幸福就醫小黃」，協助重大傷病區民就醫，評估烏來設置洗腎中心可行性。
( 四 ) 爭取設立烏來公共托育中心，完善 0-6 歲托育服務，讓幼兒在地安心就學。
( 五 ) 加碼敬老及結婚補助：70 歲 1,500 元、80 歲 3,000 元、90 歲 20,000 元；結婚補助 20,000 元。
( 六 ) 水源回饋金免申請、直接入帳，爭取提高回饋基金，落實土地正義。
二、觀光振興 ‧ 讓烏來再發光
( 一 ) 鬆綁溫泉旅宿限制，積極爭取中央、市府支持，振興觀光產業。
( 二 ) 打造文史新亮點：串聯百年吊橋、百年電廠、文化古道等特色景觀。
( 三 ) 發展深度部落旅遊，結合古道、林業台車、部落遷徙史及傳統文化。
( 四 ) 重建姻親路古道、推廣三大越嶺步道，推動步道由在地部落參與維護，共管山林。
( 五 ) 打造烏來櫻花季及櫻花公園，推動部落認養與年度觀光活動。
( 六 ) 打造溫泉步道公園及親水遊憩區，兼顧安全與觀光，吸引更多遊客。
( 七 ) 串聯烏來街、瀑布、部落商圈，推動情人步道、環山道路、信賢步道優化，帶動商圈共榮。
( 八 ) 依季節推廣桂竹筍、甜柿、香菇、高冷蔬菜、馬告及其他特色產品，結合觀光人潮辦理農產季，讓遊客「來烏來、遊烏來、吃烏來、把烏來農產帶回家」。
三、自治扎根 ‧ 守護文化尊嚴
( 一 ) 協助族譜、家族姓名、舊地名及部落地圖保存，支持部落自主辦理歲時祭儀，並編列預算由公法人依計畫辦理。
( 二 ) 推動傳統服飾及工藝補助，延續文化、凝聚族群認同。
( 三 ) 成立部落耆老諮詢團，定期召開部落聯繫會議，讓長者智慧參與治理。
( 四 ) 一部落一多功能聚會所，結合文化、祭儀、停車、運動及生活需求。
( 五 ) 成立文化推展工作小組，保存及推廣各族群與新住民文化。
( 六 ) 家家有溫泉，分階段推動溫泉水源鑽井及家戶接管。
( 七 ) 土地正義 : 專案推動回復孝義阿玉林業文化聚落、加九寮台車文化聚落、屯鹿哈盆舊社遷移及烏來部落雅各托兒所等土地正義權益回復案件。
( 八 ) 重現 Llyung Tranan 德拉楠流域文化記憶，串聯福巴、哈盆、加九寮、大桶山等歷史文化廊道。
( 九 ) 快速解決問題發揮最大效益，編列各里里長小型零星工程建議款 20-40 萬元落實基層建設
( 十 ) 編列各宗教團體相關活動經費。
四、人才培力 ‧ 青年返鄉創生
( 一 ) 優化優秀人才獎勵制度，不分族群，公平獎勵在地人才。
( 二 ) 補助考取公務員、警察、律師及國家專業證照，鼓勵區民提升專業能力。
( 三 ) 培訓低碳飲食、在地料理及食譜研發人才，打造烏來特色飲食。
( 四 ) 培訓山林嚮導、溯溪嚮導及水域安全人才，創造青年就業機會。
( 五 ) 建立烏來觀光計程車統一識別標示，提升旅遊服務品質
五、智慧防災 ‧ 建設更安全
( 一 ) 爭取「烏來聯合行政中心」，整合公所、衛生所、代表會及戶政地政等公共服務。
( 二 ) 改善停車及公共空間，活化既有空間，尋求立體停車解決方案。
( 三 ) 打造智慧防災系統，建置 LINE「拍照定位、自動通報」功能。
( 四 ) 公開工程復原進度，讓居民隨時掌握災後修復進度。
( 五 ) 改善舊有公墓水土保持及景觀，推動公墓公園化及專案推動烏來區各里公墓（納骨牆）設置及可行性。
( 六 ) 解決烏來部落停車問題，推動停車場土地取得及商圈規劃。
六、主動擔當 ‧ 透明治理
( 一 ) 成立大型活動協調平台，兼顧觀光發展與居民生活品質。
( 二 ) 重大活動落實充分溝通與知情同意，尊重地方與部落意見。
( 三 ) 每年至少召開一次里民大會，公開聽取民意並追蹤決議。
( 四 ) 建立公所志工服務隊，協助便民接待及基層服務。
( 五 ) 主動協調、積極承擔、公開透明，讓區政更有效率、更貼近人民。
