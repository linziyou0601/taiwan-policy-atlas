# Rule Skill 骨架

Rule 型 skill 之 SKILL.md 章節骨架。Rule 型於使用者編輯對應檔案時自動注入撰寫規範，描述產物應有的樣貌。建立或改寫 Rule 型 skill 時，先依本骨架起稿再填入領域規範。

## 章節骨架

```markdown
---
name: rule-{domain}
description: {規範什麼 + 適用於哪些檔案}
---

# {顯示名}

## 目的

{一句話說明本 rule 覆蓋的範疇}

## 適用範圍

{自動套用範圍：綁定檔案者列 glob，綁定動作者列觸發動作}

## {領域規範章節 1..n}

{具體規則。表格優先，祈使語氣。章節名依領域自訂}

## 參考文件

{選用：每檔一行 markdown link 加一句用途}

## 審查掛鉤

{供審查消費的反例清單與條目編號對照}

## 邊界

{治理邊界與歸屬，以正向動作條款收尾}
```

## 章節約定

| 章節 | 約定 |
|---|---|
| 目的 | 一句話。範疇之外的主題指明歸屬的權威來源 |
| 適用範圍 | 界定自動套用的邊界，與 description 的觸發條件一致。依規範對象選表述形式：規範綁定特定檔案時列 glob，綁定特定動作時列觸發動作 |
| 領域規範章節 | 章節名依領域內容自訂，同 skill 內維持一致的粒度。規則量大時抽出 `{topic}-catalog.md` 與同名子目錄條目 |
| 參考文件 | 選用。有 reference 檔時列出，置於審查掛鉤之前 |
| 審查掛鉤 | 每條反例附條目編號，審查型 skill 以編號引用 |
| 邊界 | 章節名可為邊界、作業邊界或紀律。逐條正向動作條款 |

## 骨架外事項

- 章節標題譯名依 [section-dictionary](section-dictionary.md)。
- 型錄條目檔之固定欄位依 section-dictionary 的型錄卡章節對照。
- 內容一律描述規範的現在樣貌，遷移殘影詞與空話詞由 `scripts/quick_validate.py --structure` 的文風檢查攔截。
