# Other Skill 骨架

Other 型 skill 之 SKILL.md 章節骨架。Other 型涵蓋 meta、工具與 coach 類，結構最寬鬆。建立或改寫 Other 型 skill 時，先依本骨架起稿，依實際互動形態增減章節。

## 章節骨架

```markdown
---
name: {依用途命名}
description: {做什麼 + 何時使用}
---

# {顯示名}

## 用途

{做什麼、何時使用}

## 輸入

| 輸入 | 必要性 | 說明 | 預設 |
|---|---|---|---|

## 執行指引

{執行步驟}

## 輸出格式

{有結構化輸出時必填}

## 完整性檢查

{有明確交付物時必填}
```

## 章節約定

| 章節 | 約定 |
|---|---|
| 用途 | 必要 |
| 輸入 | 無輸入時省略，有輸入時用標準 4 欄表 |
| 執行指引 | 必要 |
| 輸出格式 | 互動型 coach 可省略 |
| 完整性檢查 | 有明確交付物時必填 |

## 骨架外事項

- 章節標題譯名依 [section-dictionary](section-dictionary.md)。
- 涉及 reference 檔或事實陳述時，新增「防幻覺」章節，置於輸出格式之後。
- 內容一律描述 skill 的現在樣貌，遷移殘影詞與空話詞由 `scripts/quick_validate.py --structure` 的文風檢查攔截。
