# 欄位寫法

主張表各欄的判讀例與寫法。受控欄位的定義、共同寫法與詞例見 [docs/vocabulary.md](../../../../docs/vocabulary.md)。

## 受控欄位

| 欄位 | 判讀例 |
|---|---|
| 主體 | 原文沒寫時依政策性質判斷：修法寫立法院，其餘行政措施寫中央政府，例如「下修選舉年齡」寫立法院 |
| 動作 | 「延至12歲」寫延長，「擴充疫苗基金」寫擴大 |
| 對象 | 「軍人加薪」的對象是軍人待遇，受益是軍人 |
| 工具 | 「透過科技研發、金融支持與碳定價」寫價格機制、產業政策 |
| 受益 | 「青年購屋超低利貸款」寫青年、購屋者 |
| 條件 | 「（排富）」寫排富，「第三胎以上」寫胎次門檻 |
| 數量 | 「達到GDP的3%」寫占國內生產毛額比例 |
| 時程 | 「任內逐年達到」寫任期內、逐年 |
| 財源 | 「每年國庫撥補」寫國庫撥補 |

- 原文沒有寫財源時，現金給付與預算投入類的工具可以寫政府預算，因為這兩種工具必然由預算支應。具體度的財源判準仍只看原文，這種情形評未明示。
- 立場表態、立法與設立機構類的主張沒有經費可言，財源寫 -。
- 標題提供的領域寫進欄位，例如標題「長照保險」下的「成立中央長照保險局」，對象寫長照保險。

## 其他欄位

| 欄位 | 寫法 |
|---|---|
| 代碼 | `{選區代碼}-{號次}-{三位序號}`，依原文出現順序編號，之後再拆出新主張時，該候選人的主張全部重新編號 |
| 參選者 | 名冊對象代碼，例如 `2024-president:national:2` |
| 段落 | `transcripts.tsv` 的段落代碼 |
| 原文起、原文迄 | 先寫 -，由 `fill-offsets` 填入 |
| 原文 | 段落中連續的一段，一字不差 |
| 現任政府計畫 | 現任者延續執政團隊已宣布、尚未完成的計畫寫是，其餘寫否，非現任者一律寫否。原文寫「持續」「續推」「2.0」「3.0」，或計畫名稱是執政團隊已推出的方案時寫是。公報寫成時已完成的政績不收成主張，寫成時仍在立法或執行中的寫是 |
| 理由 | 這則主張主張什麼，以及拆分或取捨的理由 |
| 方法、審核狀態 | 方法寫「模型判讀」，審核狀態寫「模型審閱、未經獨立複評」 |

## 待審詞

詞表沒有適合的名稱時，依 SKILL.md 第 4 步寫進 `vocab-pending.tsv`。判斷是否需要新詞：

- 既有詞的說明涵蓋這個概念時沿用，例如「落實客家基本法」沿用強化，不新增落實。
- 既有詞只是字面相近、說明不涵蓋時提新詞，例如「通過『健康憲章』」沒有涵蓋它的既有對象，新增對象「健康憲章」，工具寫制度設計。
- 同一概念在不同候選人的原文用字不同時，只登錄一個名稱，例如「長壽經濟」與「高齡產業」都寫高齡產業。

## 具體度評分

每則主張對 `rubric-specificity.tsv` 的每條判準各評一列。

| 級距 | 證據 | 理由 |
|---|---|---|
| 完整明示 | 原文中符合「完整明示」欄的一段 | 「原文寫出『證據』，符合完整明示：判準描述」 |
| 部分明示 | 原文中符合「部分明示」欄的一段 | 同上，換成部分明示 |
| 未明示 | - | 寫原文缺了什麼，例如「原文沒有說明經費從哪裡來」 |
| 不適用 | - | 寫為何沒有這個面向，例如「立法不涉及經費」 |

- 「百億」這類概數評部分明示，有確切數字與基準時評完整明示。
