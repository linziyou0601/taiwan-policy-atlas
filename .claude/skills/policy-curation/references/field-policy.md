# 欄位寫法

主張表各欄的判讀例與寫法。受控欄位的定義、共同寫法與詞例見 [docs/vocabulary.md](../../../../docs/vocabulary.md)。

## 受控欄位

| 欄位 | 判讀例 |
|---|---|
| 主體 | 「下修選舉年齡」寫立法院，「國道延伸」「汰換台水的老舊管線」寫中央政府，「督促縣府興建運動中心」寫地方政府 |
| 動作 | 「延至12歲」寫延長，「擴充疫苗基金」寫擴大，「爭取興建活動中心」寫新增 |
| 對象 | 「軍人加薪」的對象是軍人待遇，受益是軍人 |
| 工具 | 「透過科技研發、金融支持與碳定價」寫價格機制、產業政策 |
| 受益 | 「青年購屋超低利貸款」寫青年、購屋者 |
| 條件 | 「（排富）」寫排富，「第三胎以上」寫胎次門檻，「拓寬 6 米以下的巷道」寫寬度門檻 |
| 數量 | 「達到GDP的3%」寫占國內生產毛額比例，「道路拓寬為 20 米」寫寬度 |
| 時程 | 「任內逐年達到」寫任期內、逐年 |
| 財源 | 「每年國庫撥補」寫國庫撥補 |

- 主體在原文沒有寫明時依政策的權責判斷：修法寫立法院，訂定或修正自治條例寫地方議會，中央權責的行政措施寫中央政府，地方權責的寫地方政府。設施依主管機關判斷，督促、監督某項政策時依那項政策判斷。
- 原文寫「爭取」「督促」時，動作寫被爭取、督促的那件事對對象的改變。
- 尺度用來界定適用範圍時寫條件，是要達到的規格時寫數量。
- 財源欄只寫原文寫出的經費來源，原文寫出的做法本身就是一種財源時照寫。
- 做法不需要經費時，財源寫 -。
- 標題提供的領域填入欄位，例如標題「長照保險」下的「成立中央長照保險局」，對象寫長照保險。

## 其他欄位

| 欄位 | 寫法 |
|---|---|
| 代碼 | `{選區代碼}-{號次}-{三位序號}`，依原文出現順序編號，之後再拆分出新主張時，該候選人的主張全部重新編號 |
| 參選者 | 名冊對象代碼，例如 `2024-president:national:2` |
| 段落 | `transcripts.tsv` 的段落代碼 |
| 原文起、原文迄 | 先寫 -，由 `scripts/offsets.py` 填入 |
| 原文 | 段落中連續的一段，與轉錄稿一字不差，不含條目編號與項目符號 |
| 現任政府計畫 | 是或否，判斷方式見下方的「現任政府計畫」 |
| 理由 | 這則主張主張什麼，以及拆分或取捨的理由 |
| 方法、審核狀態 | 方法寫「模型判讀」，審核狀態寫「未經獨立複評」 |

### 現任政府計畫

現任者延續執政團隊的計畫，而且公報發布時仍在立法或執行中，寫是，其餘寫否。

- 現任者是名冊標為現任的參選人。
- 執政團隊是這場選舉的職位所屬政府的行政部門：中央的選舉是總統與行政院，地方的選舉是該縣市或鄉鎮市的政府。
- 原文寫持續推動、續辦或擴大執政團隊的方案，或寫出執政團隊已推出的方案名稱時寫是。
- 原文寫持續爭取、督促、關注或要求時，是參選人自己的爭取與監督，寫否。
- 上級政府的方案由執政團隊執行時寫否，例如縣市政府執行中央的長照 2.0。

## 具體度評分

每則主張對 `rubric-specificity.tsv` 的每條判準各有一列評分，依判準表各級距欄的描述選擇 `rubric-levels.tsv` 的級距。

| 級距 | 證據 | 理由 |
|---|---|---|
| 完整明示 | 原文中符合「完整明示」欄的一段 | 「原文寫出『證據』，符合完整明示：判準描述」 |
| 部分明示 | 原文中符合「部分明示」欄的一段 | 同上，換成部分明示 |
| 未明示 | - | 寫原文缺少什麼，例如「原文沒有說明經費從哪裡來」 |
| 不適用 | - | 寫為何沒有這個面向，例如「做法不需要經費」 |

- 只依這則主張的原文評分，同段其他主張的數字、期限不能用來加分。
- 金額或數量只寫概數時評為部分明示，有確切數字與基準時評為完整明示。
- 做法不需要經費時，財源判準評為不適用。
- 督促、監督某項建設或政策時，依那項建設或政策本身評分。
- 群體寫在法案或機關名稱中時，對象評為部分明示。
- 只寫出合作或交流的對方，沒有寫出受益的群體時，對象評為未明示。
