# 出題與中立性

題目來自本選舉候選人的主張，每題至少一筆配題證據。題目的命題是政策方向，讓沒有讀過政見的人也能依自己的立場作答。

## 題目欄位

| 欄位 | 寫法 |
|---|---|
| 代碼 | `q.{面向代碼}`，子題沿用母題面向時加上一段後綴，例如 `q.labor.wage.minimum.target` |
| 面向 | 分類樹的節點，與配題列的面向相同 |
| 母題 | 根題（沒有母題的題目，網站上稱主問題）寫 -，子題（網站上稱追問題）寫母題代碼 |
| 題幹 | 一句話，以「政府應」「某某應」陳述，句末使用句號 |
| 說明 | 解釋題幹的專有名詞，提到現況時依下方的「說明的現況」 |
| 顯示條件 | 根題寫 -。子題寫「中立、同意、非常同意」，母題回答這三種時才追問，加碼的子題對不同意母題的人沒有意義 |
| 預算份額 | 根題寫 1，子題寫 0.5，網站依實際出現的題目正規化 |
| 適用範圍 | 全部選區寫「全部」，只適用部分選區時寫選區代碼 |
| 版本 | 第一次發行前都是 1。發行後題幹、說明、面向或顯示條件修改後加 1，配題要依新版重新核對 |

### 說明的現況

題組是一場選舉當時的紀錄，說明的現況以投票日為準：

- 寫「{年} 年選舉時」，例如「2024 年選舉時沒有這部法律」。
- 只寫投票日前的一手來源能查證的事實，例如法規資料庫的施行日期、政府公告。
- 直接陳述當時的狀態，不寫預設之後會完成的「尚未」。

## 母題與子題

1. 候選人方向相同、做法或金額不同的面向寫一道母題與數道子題。母題採用共同方向，例如「政府應增加對育兒家庭的現金補助」，子題詢問各自的做法，例如生育補助、育兒津貼延長年齡、扣除額。
2. 子題的金額或年份採用某位候選人原文的數字，其他候選人的數額依 `rubric-stance.tsv` 判斷立場。
3. 沒有提出數字或沒有提到子題做法的候選人不建立子題的配題，記為未知。
4. 主張只分配到子題時，同一則主張再新增一列母題的配題，兩列的分配各半。子題判為反對、方向與母題相同時，母題判為支持。

<br>

## 意識形態軸

每題對 `axis-ideology.tsv` 有關的軸各寫一列 `question-axes.tsv`，代碼寫 `{題目代碼}-{軸代碼}`。

| 欄位 | 寫法 |
|---|---|
| 方向 | 同意時往正極寫 1，往負極寫 -1 |
| 權重 | 題目直接表達這個軸的取向寫 1，只是間接相關寫 0.5 |
| 理由 | 「同意表示…，往某一極」，權重 0.5 時說明為何只是間接相關 |

- 增加政府支出的題目對財政緊縮軸寫 -1、0.5。擴大公共給付或照顧的題目對擴大福利國家軸寫 1、1。
- 兩岸題目分清統獨立場與兩岸交流：前者詢問最終關係，後者詢問往來的多寡。
- 不確定方向的題目不寫軸，例如維持兩岸現狀。

<br>

## 中立性審查

每題對 `rubric-neutrality.tsv` 的每條判準各寫一列 `neutrality.tsv`，代碼寫 `{題目代碼}-{判準代碼}`，結果全為通過才能發布。不通過時改寫題幹，依題目欄位的版本規則處理，重新審查並重新核對該題的配題。各判準的審查方式：

| 判準 | 審查方式 |
|---|---|
| 正反可答 | 題幹是可以同意或不同意的政策方向，事實陳述與價值口號改寫成政策方向 |
| 無評價用語 | 比對 `rubric-neutrality.tsv` 這條判準說明欄的評價詞清單 |
| 不洩漏身分 | 比對候選人姓名、黨名、`aliases.tsv` 與候選人自訂的計畫名稱，例如「2.0」「3.0」 |
| 不預設事實 | 題幹不把有爭議的事實寫成前提，現況只寫在說明欄 |
| 用語可懂 | 專有名詞在說明欄解釋 |
| 單一命題 | 一題只問一個方向。合併兩項時，理由要寫明兩項為何是同一方向 |
| 用字統一 | 題幹的對象與配題主張的對象欄使用詞表的同一個名稱 |
